Setup Guide

Run your models without touching the browser

A small Playwright script that drives discountingcashflows.com's model editor for you — paste a main.py in, pick a ticker, and it runs the same way as if you'd done it by hand.

✓ Node.js installed ✓ Your own free DCF account
01

Install dependencies

From the automation/ folder, install Playwright and download a Chromium browser for it to drive.

# from inside automation/
npm install
npx playwright install chromium
Linux / WSL only 
sudo npx playwright install-deps chromium

Windows and macOS don't need this step — Chromium runs out of the box there.

02

Log in once

Opens a real browser window to discountingcashflows.com and waits for you to log in — however long that takes.

node login.js
⚠ Check “Remember me” before clicking Login. Without it, the site only issues a browser-session cookie that disappears the moment the window closes — your login won't stick.
03

Run a model

Point it at either model's main.py and a ticker. A window opens, pastes in your code, runs it, and leaves the result sitting on the Preview tab for you to look at.

node run-model.js "../Data Tables/main.py" AAPL
node run-model.js "../Forecasting Model/main.py" NVDA

Close the browser window yourself whenever you're done — nothing else to run.

04

Optional: keep a record

Add the --save flag to also write the result to disk, in addition to showing it in the browser.

node run-model.js "../Data Tables/main.py" AAPL --save

Saved to automation/runs/:

  • AAPL-Data-Tables.png— screenshot of the result
  • AAPL-Data-Tables-preview.html— raw rendered output
  • AAPL-Data-Tables-console.log— anything the script printed

Notes

  • Your login is saved outside this repo (in your home directory) and never committed.
  • If login ever stops working, just run node login.js again.
  • Financial data comes from Financial Modeling Prep, via discountingcashflows.com — this tool only automates the clicking.
